## 自动定位修复（同版本 2.3 覆盖）

日期：2026-10-15（Asia/Hong_Kong）。

用户安装 2.3 后报告自动定位失败。已在本机复现：HKCU Steam 路径使用 `d:/steam`，HKLM 和库清单使用 `D:\steam`。旧 Core 返回同一游戏目录的两种写法，自动安装将其误判为多个不同目录。

修复将 Steam 根目录、库目录及游戏结果规范为绝对 Windows 路径，在不区分大小写的集合内去重。并读取游戏 ACF 的 `installdir`，支持更名目录；仅接受 `steamapps/common` 内包含 `OnimushaWotS.exe` 的目录。缺失、损坏或不可读的单个清单不会阻断其他库。

CoreSmoke 增加并通过以下隔离临时目录测试：

- 正反斜杠、大小写、末尾斜杠及点路径指向同一目录时，仅返回一项。
- 两个真实不同的库目录仍返回两项，不擅自选择安装副本。
- 清单中的更名目录优先；清单不可读时回退至已验证的默认目录。
- 一个库的读取失败或错误根路径不影响其他有效库。
- 清单中的绝对路径或越界相邻路径被拒绝。

管理器分别提示未检测到游戏与检测到多个不同目录；多个目录时显示候选路径。保留原安装清单目录优先规则。

发布构建中的托管和原生回归测试已通过。本机修复后只读检测已返回唯一有效游戏目录。按用户要求保留产品版本 2.3、程序集版本 2.3.0.0 和原安装包文件名，用修复构建覆盖原文件。未执行安装器或修改游戏文件，真实安装/升级效果仍需用户复测。

用户要求界面去掉免费、源码公开、无需激活码等标签与重复状态小字；许可文件和功能不变，捐赠入口及禁止倒卖公告保留。
