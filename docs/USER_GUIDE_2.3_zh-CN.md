# 2.3 免费双语版使用说明

本工具非 Capcom / Sony 官方产品。免费使用，无需激活码，没有试用倒计时。

1. 关闭游戏，运行安装包，在首个语言对话框选择“简体中文”或“English”。
2. 阅读免费公告及源码公开许可，完成安装。安装器尝试定位 Steam 游戏目录；未找到时打开管理器，选择包含 `OnimushaWotS.exe` 的目录，点“安装 / 修复”。
3. 使用 USB 或蓝牙连接 DualSense，确认管理器设备状态，再启动游戏。
4. 参数页可设置左右扳机、触觉、手柄扬声器及音量。蓝牙与 USB 的听感、延迟和稳定性可能不同，Edge 蓝牙尚未完成实机验证。
5. 界面语言可在管理器内切换并保存。它不会自动改变游戏或鬼笼手语音的语言。
6. 捐赠页直接显示作者提供的支付宝和微信二维码，可在页面上扫码。捐赠自愿，不购买授权、不解锁功能。请在支付应用核对收款人和金额；软件不会读取支付状态。

官方版本免费。不要购买所谓激活码、永久授权或捐赠解锁。禁止倒卖、收费打包、强制捐赠和冒充作者官方发布；原创代码允许学习、修改及免费分发，具体条件见 `LICENSE.txt`。本许可不是 OSI 标准开源许可；第三方组件遵循其自身许可。

关闭主界面会保留托盘，双击托盘可恢复界面，托盘菜单可完全退出。REFramework 菜单默认隐藏，按 Insert 可呼出。安装、修复或卸载前应关闭游戏。

卸载会移除桥接组件并恢复安装前的 REFramework 配置。升级到免费版后旧试用或激活数据不再控制功能。管理员权限仅在写入受保护游戏目录等操作需要时请求。

自动定位已在 2.3 修复同一 Steam 路径因正反斜杠写法不同被重复计数的问题。若仍未找到，请手动浏览到包含 OnimushaWotS.exe 的目录；若检测到多个不同副本，会显示候选路径供你手动选择。
