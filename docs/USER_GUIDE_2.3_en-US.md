# Version 2.3 — free bilingual edition

This is an unofficial tool, not a Capcom or Sony product. All features are free, with no activation key or trial countdown.

1. Close the game and run setup. Choose Simplified Chinese or English in the first language dialog.
2. Read the free-release notice and source-available license. Setup attempts to locate the Steam game directory. If necessary, select the folder containing `OnimushaWotS.exe` in the manager and choose Install / Repair.
3. Connect a DualSense through USB or Bluetooth, check the device status, then start the game.
4. Configure left/right triggers, haptics, controller speaker and volume on the settings page. Bluetooth may differ from USB in sound, latency and stability. DualSense Edge Bluetooth still needs hardware verification.
5. Switch and save the interface language in the manager. This does not change the game language or gauntlet voice language.
6. The support page displays the author's Alipay and WeChat QR codes for scanning directly on the page. Donations are voluntary, do not purchase a license and do not unlock features. Confirm the recipient and amount in your payment app. The software does not read payment status.

The official release is free. Do not buy activation keys, lifetime access or donation unlocks. Third-party components retain their own licenses.

Closing the main window leaves the tray icon running. Double-click it to restore the window; use its menu to exit fully. REFramework's menu starts hidden; press Insert to show it. Close the game before installing, repairing or removing components.

Removal restores the previous REFramework configuration. Old trial and activation records no longer control features in the free edition. Administrator privileges are requested when necessary to modify protected game directories.

For issues, check the game directory, connection and other mods first. Report the game version, controller model and symptoms through the author's existing contact channels. Do not send payment passwords or keys. The software is provided as is and cannot guarantee compatibility with every setup.

Version 2.3 fixes duplicate detection caused by slash variants of the same Steam path. If automatic detection still fails, browse to the folder containing OnimushaWotS.exe. Multiple distinct installations are listed for manual selection.
